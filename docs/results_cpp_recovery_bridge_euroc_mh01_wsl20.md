## Node Contract

The node publishes `sensor_msgs/PointCloud` to:

```text
/feature_tracker/recovery_candidates
```

The message uses raw pixel coordinates:

- `points[i].x`: current-frame `u`
- `points[i].y`: current-frame `v`
- `channels[0].values[i]`: previous-frame `u`
- `channels[1].values[i]`: previous-frame `v`
- `channels[2].values[i]`: score

The original VINS C++ `FeatureTracker` remains authoritative and decides whether to accept candidates.

## Health-Triggered Request ONNX Full Test

Implementation update:

- `FeatureTracker` computes post-KLT health from active track count and lost-track ratio.
- When health is poor, it publishes `/feature_tracker/recovery_request` with previous-frame lost-track raw pixels plus `id` and `track_cnt`.
- `lightglue_recovery_candidate_node` runs ONNX only on request, pairs the requested previous frame with the current frame, and re-ranks LightGlue matches by:

```text
rank = lightglue_score - request_distance_penalty * distance_to_nearest_lost_prev
```

- Candidates outside `_request_prev_radius` of lost KLT tracks are rejected before publishing `/feature_tracker/recovery_candidates`.
- `FeatureTracker` waits briefly for candidates, accepts only a small number, then clears consumed candidates so stale matches are not reused.

- Runtime is still uneven because the pipeline model has high warm-up and occasional long inference. The decoupled `superpoint.onnx` + `superpoint_lightglue_fused.onnx` route may allow feature caching and lower request latency.

## Next Engineering Step

Do not tune VINS using `fake_grid`; it is deliberately synthetic.

The next useful work:

1. Rerun request-driven ONNX recovery on harder EuRoC sequences such as MH_04/MH_05 and V1/V2.
2. Add a lightweight geometric sanity check before accepting recovery candidates, such as local displacement consistency or an F-matrix/RANSAC gate.
3. Tune conservatively: reduce `RECOVERY_MAX_CNT` to 1-3, tighten `REQUEST_PREV_RADIUS`, and raise trigger thresholds only if full-bag metrics justify it.
4. Consider the decoupled `superpoint.onnx` + `superpoint_lightglue_fused.onnx` path to cache SuperPoint features per frame and reduce latency.
